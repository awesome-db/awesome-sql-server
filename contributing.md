# Contribution Guidelines

Thanks for helping make this list better. Please read the guidelines below before opening a pull request.

## Adding an entry

- Make sure the entry is genuinely useful to people working with SQL Server. Awesome lists are curations of the best, not everything.
- Search the list first to avoid duplicates.
- Add one entry per pull request, so it can be discussed and merged on its own.
- Use the format `- [Name](link) - Description.` and keep the description short, factual, and free of marketing language.
- Start the description with a capital letter and end it with a period.
- Keep entries in alphabetical order within their section.
- Link to the project's GitHub repository when it is open source, otherwise to its homepage.
- Only add projects that are actively maintained and documented. Deprecated, archived, or unmaintained projects will be removed.
- Commercial tools are welcome. Say that they are commercial in the description, and mention a free tier or edition when one exists.
- If you are affiliated with the project you are adding, say so in the pull request. Affiliation is fine, but please disclose it.
- Run [awesome-lint](https://github.com/sindresorhus/awesome-lint) locally with `npx awesome-lint` and fix any reported issues.
- Give your pull request a title like `Add ToolName` and a short description of why the entry belongs here.

## Other changes

Suggestions for new sections, removals, and rewording are welcome too. Open an issue or a pull request describing the change and the reasoning behind it.

## Impartiality

This list is maintained by the Beekeeper Studio team, but it is meant to serve the whole SQL Server community. Entries for competing tools are treated the same as everyone else's, and we welcome outside maintainers who want to help keep it that way.
